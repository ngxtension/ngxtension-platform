Delete the boilerplate. Keep the Angular.

ngxtension is a collection of 70+ small utilities for signals, the router, forms, RxJS and the DOM. Each one is its own entry point, so you only ship what you import.

01

Keep the search box in the URL

Instead of reading ActivatedRoute and calling the router by hand, linkedQueryParam gives you a signal that writes to the URL, and a URL that writes to the signal.

lines 16 16 → 3
Read the linkedQueryParam docs → 
export class SearchPage {
  private route = inject(ActivatedRoute);
  private router = inject(Router);

  search = toSignal(
    this.route.queryParamMap.pipe(
      map((params) => params.get('search')),
    ),
  );

  setSearch(search: string) {
    this.router.navigate([], {
      relativeTo: this.route,
      queryParams: { search },
      queryParamsHandling: 'merge',
    });
  }
}
export class SearchPage {
  search = linkedQueryParam('search');
}

03

Keep a setting in localStorage

injectLocalStorage reads the stored value, writes every change back, and follows other tabs through the storage event. What you get is a plain WritableSignal.

lines 22 22 → 7
Read the injectLocalStorage docs → 
export class ThemeToggle {
  readonly theme = signal<'light' | 'dark'>(
    JSON.parse(
      localStorage.getItem('theme') ?? '"light"',
    ),
  );

  constructor() {
    effect(() => {
      localStorage.setItem(
        'theme',
        JSON.stringify(this.theme()),
      );
    });

    fromEvent<StorageEvent>(window, 'storage')
      .pipe(takeUntilDestroyed())
      .subscribe((e) => {
        if (e.key === 'theme' && e.newValue) {
          this.theme.set(JSON.parse(e.newValue));
        }
      });
  }
}
export class ThemeToggle {
  readonly theme = injectLocalStorage<
    'light' | 'dark'
  >('theme', {
    defaultValue: 'light',
  });
}
