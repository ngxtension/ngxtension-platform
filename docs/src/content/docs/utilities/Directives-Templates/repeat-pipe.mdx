`RepeatPipe` turns a number into an array of consecutive integers, so you can render something N times with `@for`
without building an array in your component. Use it for skeleton loaders, star ratings, pagination links or year
pickers.

## Usage

```angular-ts
import { Component } from '@angular/core';
import { RepeatPipe } from 'ngxtension/repeat-pipe';

@Component({
	selector: 'app-skeleton-list',
	imports: [RepeatPipe],
	template: `
		<ul>
			@for (i of 3 | repeat; track i) {
				<li class="skeleton">Row {{ i }}</li>
			}
		</ul>
	`,
})
export class SkeletonList {}
```

`3 | repeat` produces `[0, 1, 2]`, so this renders:

```html
<li class="skeleton">Row 0</li>
<li class="skeleton">Row 1</li>
<li class="skeleton">Row 2</li>
```

The numbers are unique, so `track i` is all you need.

## Start at another number

Pass `startAt` as the pipe argument. `3 | repeat: 10` produces `[10, 11, 12]`.

```angular-ts
import { Component, input } from '@angular/core';
import { RepeatPipe } from 'ngxtension/repeat-pipe';

@Component({
	selector: 'app-pagination',
	imports: [RepeatPipe],
	template: `
		@for (page of pageCount() | repeat: 1; track page) {
			<a [href]="'?page=' + page">{{ page }}</a>
		}
	`,
})
export class Pagination {
	readonly pageCount = input.required<number>();
}
```

## Count down

A **negative** length produces a descending sequence that starts at `startAt`. The absolute value is the number of
items. `-5 | repeat: 2026` produces `[2026, 2025, 2024, 2023, 2022]`.

```angular-ts
import { Component } from '@angular/core';
import { RepeatPipe } from 'ngxtension/repeat-pipe';

@Component({
	selector: 'app-year-select',
	imports: [RepeatPipe],
	template: `
		<select>
			@for (year of -5 | repeat: 2026; track year) {
				<option [value]="year">{{ year }}</option>
			}
		</select>
	`,
})
export class YearSelect {}
```

A length of `0` produces an empty array.

## With `*ngFor`

The pipe returns a plain array, so it also works with `*ngFor` in templates that still use it:

```html
<li *ngFor="let i of 3 | repeat">{{ i }}</li>
```

`*ngFor` doesn't set a `trackBy` here. If you're on `*ngFor`, the [Repeat directive](/utilities/directives-templates/repeat/)
(`*ngFor="let i; repeat: 3"`) sets one for you. For new code, prefer `@for` with this pipe.

## API

```ts
// {{ length | repeat: startAt }}
class RepeatPipe {
	transform(length: number, startAt?: number): number[];
}
```

| Argument  | Type     | Default | Description                                                                                      |
| --------- | -------- | ------- | ------------------------------------------------------------------------------------------------ |
| `length`  | `number` | -       | How many numbers to produce. Positive counts up, negative counts down, `0` gives an empty array. |
| `startAt` | `number` | `0`     | The first number of the sequence.                                                                |

Both arguments must be integers. Anything else (including `NaN` or `1.5`) throws an error such as
`[Repeat] repeat requires an integer but "1.5" is passed in`.
